Entry for the make.fun competition
[Sorry, I Heard That Wrong](https://make.fun/c/u-kiencx-sorry-i-heard-that-wrong-1858c729):
a program that writes the funniest one-line apology a smart speaker gives
after mishearing its owner.

`main.py` writes a single line (77 characters) to `/output/entry.txt`:

> Sorry — I heard 'wake me at seven' and woke you at seven. PM. You're welcome.

Run it with `python3 main.py`. The output is deterministic: every run
produces byte-identical text.
